## 1.0.0 (2026-11-02)

### Added
- First release. Underlines spelling, grammar and style mistakes while you write, with up to five suggestions, using the LanguageTool server your administrator set up (self-hosted, with an optional access token, or the public api.languagetool.org if allowed). Nothing is sent while a message is set to be signed or encrypted (Bulwark 1.20 and later).
- Only new or changed paragraphs are sent; unchanged ones are answered from memory.
- Personal dictionary, an organisation word list, Ignore per message, turned-off rules, picky mode, native language, spelling variants and an optional warning before sending.
- Administrators can lock language, level and turned-off rules for everyone.
- In all 30 languages Bulwark ships.
